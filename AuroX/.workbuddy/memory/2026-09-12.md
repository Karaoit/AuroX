# 2026-09-12

## ParameterSpace API 易用性重构
- 用户认为原 `StructuredSpace` 命名/注册方式不方便，要求缩短并去掉 bind 时的重复字符串。
- 改动（均在 `include/AuroX/Space/ParameterSpace.{hpp,ipp}`，并同步 `README_CN.md`）：
  - `StructuredSpace<Derived>` → `PStruct<Derived>`（Parameter Struct 缩写）。保留 `template<typename D> using StructuredSpace = PStruct<D>;` 向后兼容别名（可删）。
  - `AUROX_STRUCTURED_PARAMS` → `AUROX_PARAMS`（仅生成 `for_each_param`）。
  - 新增 `AUROX_REG(...)`：替代 `registerParams([this](auto& space){...})` 样板。
  - 新增 `AUROX_BIND(param, ...)`：`#param` 字符串化变量名为注册名，调用 `param.bind(space, "param", ...)`，去掉手写字符串。
- 仓库内无真实调用点（仅头文件文档示例 + README），所以纯重命名安全。
- 用 MSVC `cl /E` 做了纯预处理验证，宏展开（含 `{"a","b","c"}` 逗号穿透）正确。完整编译未做（沙箱无 json.hpp 与完整工具链）。

## ParameterSpace 第二轮易用性重构（零破坏别名 + 安全增强）
- 命名空间别名 `namespace PSpace = AuroX::Space;`（原 `PSpace` 是半成品类名，与 ActionSpace/ipp 的 `ParameterSpace` 不一致会编译失败 —— 已把类正式命名为 `ParameterSpace`）。
- 便捷类型别名：`TParam<T>` = `Param<T>`；`EParamRaw` = `EnumParameter`；`CompMeta` = `ParameterSpace::ComponentMeta`。
- 成员函数别名（零破坏）：`ParameterSpace`/`PStruct` 上 `vec()`/`unvec()`/`layout()`；`ParameterBase`/`Param`/`EnumParam` 上 `inBounds()`。
- 安全增强：`Param<T>::value` 与 `EnumParam::value` 从 public 改 protected，禁止用户绕过同步直接改成员（防数据撕裂），保留 `operator=`/`get()`。
- `ComponentMeta` 增加 `bool is_enum = false;`，在 `ParameterSpace::componentLayout()` 中按 `typeId()==Enum` 填充，解决枚举向量化无提示。
- 新增不抛异常反序列化：`ParameterSpace::tryFromJson` / `PStruct::tryFromJson`（noexcept try/catch 包 fromJson）+ 模板 `tryLoadJson(SpaceT&, path)`（读文件→parse→tryFromJson）。
- `PStruct::validate()` 增加 `#ifndef NDEBUG` 断言：遍历 `for_each_param`，任一成员 `!isBound()` 即 assert 失败，捕获漏写 `PARAM_BIND`。
- 宏重命名：`AUROX_REG`→`PARAM_REG`，`AUROX_BIND`→`PARAM_BIND`；保留 `#define AUROX_REG PARAM_REG` / `#define AUROX_BIND PARAM_BIND` 向后兼容垫片。`AUROX_PARAMS` 未改名。
- 修复头文件末尾错误 `#include "PSpace.ipp"` → `#include "ParameterSpace.ipp"`。
- 同步刷新 `README_CN.md` 宏名（`AUROX_PARAMS`/`PARAM_REG`/`PARAM_BIND`）。
- `.cpp` 全部 `PSpace::`/`PSpace&` → `ParameterSpace`/`ParameterSpace&`（类更名后必须）。
- 注意：Edit 工具对 Space 头文件会静默丢弃编辑（尤其 replace_all 与多编辑），本回合改用 Python 脚本批量改写并断言校验，可靠。
