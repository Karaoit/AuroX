## 10.11 表格 7 项缺陷修复（第二轮）

依据用户截图表格（7 项，P1×4 + P2×3），只改表中提及的 5 个文件、英文注释、其余不动。

**ParameterSpace**（`ParameterSpace.hpp` / `.ipp` / `src/Space/ParameterSpace.cpp`）
- P1 参数双份值同步：`Param<T>::raw()` / `EnumParam::raw()` 只保留 **const** 重载，禁止 `raw()->value=...` 直写底层（写入统一走 `operator=`）。
- P1 JSON 结构校验：`fromJson()` 现在要求根为 object 且含 `parameters` 数组、每条目为 object 且带 `type`/`name`；`createParameter` 不再默认 `type=float`。缺失/类型错→抛异常，配合临时空间提交保证原空间不变（此前 `tryFromJson({})` 返回 true 且清空空间）。
- P1 写入绕过校验：新增 `TypedParameter<T>::accepts(cand)` 作为**唯一**合法性判据，`isWithinBounds()`/`acceptsDouble()`/`unvectorize<T>()` 全走它。`unvectorize<T>({100})` 越界现抛异常（原来直写 `[0,3]` 参数）。
- P2 整数边界：`NumericTraits<T>` 增加 `fits(double)`，`acceptsDouble` 先 `fits` 再 `back`（int 先判 [INT_MIN,INT_MAX] 再 llround，避免 UB；float 防溢出）。`EnumParameter::acceptsDouble` 先夹到 [0,labels-1] 再 llround。

**ActionSpace**（`ActionSpace.hpp` / `src/Space/ActionSpace.cpp`）
- P1 失败语义统一：`plan()` 增加 goal 有限性校验，NaN 目标现返回 `Chain{why="non-finite goal"}` 而非抛异常。
- P2 BFS 去重：新增 `VecHash` + `exactSeen` 位精确哈希索引，命中 O(1)；未命中回退原 eps 线性扫描，**语义不变**（真正的量化哈希索引仍属“大规模前评估”的待定项，未引入）。
- P2 名称歧义：`get(type,name)` 改为 hash(`type+"/"+name`) O(1) 查找（带线性回退）；新增 `run(type,name)` 消歧执行。`get/run(name)` 保留首匹配语义。

**验证**：MSVC `cl /std:c++20 /utf-8 /W4` 零警告；临时 harness 覆盖全部 7 项断言 ALL PASS（临时目录已删）。
